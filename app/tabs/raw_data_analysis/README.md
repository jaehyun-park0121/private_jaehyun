# 원시 데이터 분석 탭

문서/페이지 단위 원시 JSON 박스 데이터를 읽어 도서 단위 집계표를 만들고, 관련 페이지 미리보기, 분포 통계, 엑셀 저장, 구글 스프레드시트 반영까지 지원하는 탭입니다.

이 탭은 크게 두 축을 함께 봅니다.

- DLA가 만든 박스 구성 자체가 어떤지
- `flags.text` 기준 텍스트 추출 품질이 어느 정도인지

## 이 탭이 참조하는 데이터

- 입력 단위: S3에 저장된 페이지별 JSON 파일
- 기본 전제:
  - 각 JSON에는 `shapes` 배열이 있고, 각 shape에는 `label`, `points`, `flags.text` 등이 들어 있습니다.
  - 미리보기 이미지는 JSON과 같은 경로, 같은 stem의 `.png` 파일을 찾는 방식으로 연결합니다.
- 도서 단위 묶음 기준:
  - `book_name`: JSON 파일의 상위 폴더명
  - `file_name`: JSON 파일명

즉, 같은 폴더 아래 있는 페이지 JSON들을 모아 한 권의 도서로 집계합니다.

## 폴더 구조

- `page.py`: 탭 상위 UI 조립, 분석 실행/중지, 미리보기 연동, 엑셀/구글 시트 저장
- `analysis_core.py`: S3 조회, 페이지 단위 집계, 도서 단위 합산, 병렬 처리
- `worker.py`: `QThread` 기반 분석 실행 래퍼
- `ui_shared.py`: 결과표 컬럼 정의, 도움말 문구, 하이라이트 규칙, 공통 스타일
- `panels/left_panel.py`: 입력 조건, 텍스트 검사 대상 라벨, 하이라이트 규칙, 출력 설정
- `panels/center_panel.py`: 도서 단위 결과표와 셀 하이라이트
- `panels/right_panel.py`: 페이지 미리보기, 분포 통계 카드
- `widgets/image_viewer.py`: 페이지 이미지와 박스 오버레이 렌더링
- `widgets/multi_select_button_group.py`: 텍스트 검사 대상 라벨 다중 선택 버튼

## 실행 흐름

1. 왼쪽 패널에서 S3 URL, AWS 정보, 결과 폴더, 텍스트 검사 대상 라벨을 설정합니다.
2. `analysis_core.py`가 S3에서 JSON 목록을 모은 뒤 페이지별 JSON을 읽습니다.
3. 각 페이지에서 박스 수, 라벨 분포, 텍스트 통계, 품질 지표를 계산합니다.
4. 같은 도서에 속한 페이지를 묶어 도서 단위 집계표를 만듭니다.
5. 가운데 패널에 도서 단위 결과표를, 오른쪽 패널에 분포 통계 카드를 갱신합니다.
6. 결과표 셀을 선택하면 해당 지표와 관련 있는 페이지 후보를 정렬해 오른쪽 패널 미리보기에 보여줍니다.
7. 필요하면 엑셀 저장 또는 구글 스프레드시트 업데이트를 수행합니다.

분석 실행만으로 파일이 자동 저장되지는 않습니다. 분석 후 `엑셀로 저장하기` 또는 `구글 스프레드시트 입력`을 별도로 눌러야 출력이 반영됩니다.

## 화면 구성

### 왼쪽 패널

- `텍스트 검사 대상 라벨`
  - 텍스트 관련 지표 계산에 포함할 라벨을 고릅니다.
  - 기본 선택은 `TEXT`, `TITLE`, `CAPTION`, `FOOTNOTE` 계열입니다.
  - 선택 결과는 `띄어쓰기`, `영어`, `기타 외국어`, `특수문자`, `어절`, `빈 텍스트 박스` 계산에만 영향을 줍니다.
- `하이라이트 규칙`
  - 하위 퍼센트 / 상위 퍼센트
  - 띄어쓰기 최소 / 최대
- `출력`
  - 결과 폴더 선택
  - 구글 스프레드시트 URL, 탭명 입력

### 가운데 패널

- 도서 단위 집계표를 보여줍니다.
- 각 컬럼은 숫자 기준으로 하이라이트됩니다.
- 컬럼 도움말 툴팁은 `ui_shared.py`의 정의를 그대로 사용합니다.

### 오른쪽 패널

- `미리보기` 탭
  - 선택한 셀과 관련 있는 페이지를 순서대로 보여줍니다.
  - 관련 박스는 강조하고, 나머지 박스는 tone-down 처리합니다.
- `통계` 탭
  - 각 지표별 분포 차트, 평균, 중앙값, 범위, 기준 초과 비율을 보여줍니다.

## 결과표 항목 정의

결과표는 도서 단위 집계입니다. 다만 일부 지표는 페이지 단위로 먼저 계산한 뒤 도서 단위로 합산합니다.

또한 아래 항목 중 텍스트 통계 계열은 전체 박스를 기준으로 계산하지 않고, 왼쪽 패널의 `텍스트 검사 대상 라벨` 선택값만 대상으로 계산합니다.

### DLA 구성

- `텍스트`
  - `TEXT` 라벨 박스 수
- `타이틀`
  - `TITLE` 라벨 박스 수
- `캡션`
  - `CAPTION` 라벨 박스 수
- `이미지`
  - `IMAGE` 라벨 박스 수
- `수식`
  - `LATEX`, `EQUATION`, `FORMULA`, `MATH` 라벨 수의 합
- `표`
  - `TABLE` 라벨 박스 수
- `차트`
  - `CHART` 라벨 박스 수
- `각주`
  - `FOOTNOTE` 라벨 박스 수
- `아이템`
  - `ITEM` 라벨 박스 수
- `다단 의심`
  - 페이지별로 다단 의심 여부를 먼저 계산한 뒤, 도서 안에서 의심 페이지 수를 합산합니다.
  - 판정 방식은 다음과 같습니다.
    - 먼저 다른 박스에 완전히 포함되는 박스를 제거합니다.
    - 남은 박스들 중 면적이 0보다 큰 박스만 후보로 봅니다.
    - 두 박스의 y축 구간이 조금이라도 겹치면 다단 의심으로 판단합니다.
  - 즉, 현재 구현은 "좌우 열 분리"를 직접 계산하는 방식이 아니라 "같은 높이대에 병렬 배치된 박스가 있는가"를 보는 간단한 휴리스틱입니다.

### DLA 추론 품질

- `박스(<2)`
  - 페이지 전체 박스 수가 2개 미만인 페이지 수입니다.
  - 현재 구현은 원시 박스 개수(`total_boxes`)를 그대로 사용합니다.
  - `다단 의심`과 달리, 이 지표는 포함 박스를 제거한 뒤 다시 계산하지 않습니다.
  - 보통 DLA 추론이 크게 실패한 페이지는 박스가 1개 수준으로 뭉개지는 경우가 많다는 가정을 바탕으로 확인용 지표로 사용합니다.

### Fitz 구성

이 영역은 선택한 `텍스트 검사 대상 라벨`의 `flags.text`만 이어 붙여 계산합니다. 페이지 단위 계산 후 도서 단위로 합산하거나 비율을 다시 계산합니다.

- `어절`
  - 전체 텍스트를 공백 문자 `" "` 기준으로 split 한 뒤, 비어 있지 않은 토큰 수를 셉니다.
  - 줄바꿈은 분리 기준이 아니고, 단순 띄어쓰기 기준에 가깝습니다.
- `띄어쓰기`
  - `(space 개수) / (전체 문자 수)`
  - 여기서 space는 `" "` 하나만 셉니다.
- `영어`
  - `(영문자 수) / (전체 언어 문자 수)`
  - 영문자 수는 `[A-Za-z]` 정규식 기준입니다.
- `기타 외국어`
  - `(전체 언어 문자 수 - 한국어 문자 수 - 영문자 수) / (전체 언어 문자 수)`
  - 언어 문자 수는 `\p{L}` 기준입니다.
  - 한국어는 `\p{Hangul}` 기준으로 잡습니다.
- `특수문자`
  - `(특수문자 수) / (전체 문자 수)`
  - 현재 구현은 아래 정규식을 그대로 사용합니다.

```python
SPECIAL_CHAR_PATTERN = regex.compile(
    r"[^A-Za-z0-9가-힣~!@#$%^&*()_\+\-=\[\]{}\|;:'\",<\.>/\?`\n]"
)
```

구현 메모:

- 언어 문자 판별은 `regex` 라이브러리의 Unicode 속성 정규식을 사용합니다.
- `full_text`는 각 박스의 `flags.text`를 `\n`으로 이어 붙인 문자열입니다.
- 현재 정규식 구현상 `\n`은 제외되지만 일반 공백(space)은 허용 문자에 포함되지 않아 `특수문자` 집계에 반영될 수 있습니다. 문서상 기대 규칙과 실제 집계가 달라지지 않도록 이 점을 같이 확인하는 편이 좋습니다.

### Fitz 추론 품질

- `빈 텍스트 박스`
  - 선택한 `텍스트 검사 대상 라벨` 중 `flags.text`가 비어 있거나 공백뿐인 박스 수입니다.
  - 이미지형 텍스트, OCR 미반영, 텍스트 추출 실패 여부를 빠르게 확인할 때 보는 지표입니다.

## 하이라이트와 통계 규칙

### 가운데 결과표 하이라이트

- 대부분의 컬럼
  - 하위 `n%` 경계 이하는 연한 빨강 배경
  - 상위 `n%` 경계 이상은 연한 초록 배경
- `띄어쓰기`
  - 기본 허용 범위는 `0.20 ~ 0.33`
  - 범위 밖 값은 진한 빨간 글씨 + bold 처리
- `빈 텍스트 박스`, `박스(<2)`, `다단 의심`
  - 기본 기준값은 `0`
  - 기준 초과 값은 주황 계열 글씨 + bold 처리

하이라이트 기준은 왼쪽 패널에서 조정할 수 있고, 가운데/오른쪽 패널에 함께 반영됩니다.

### 오른쪽 통계 패널

- 전체 요약
  - 도서 수, 페이지 수, 현재 하이라이트 기준 요약
- 지표별 카드
  - 분포 차트
  - 평균 / 중앙값
  - 최소 / 최대
  - 기준 초과 권수와 비율

`띄어쓰기`는 고정 기준(`space_min`, `space_max`)을 쓰고, 나머지 대부분의 지표는 분포 하위/상위 퍼센트 경계를 참고합니다.

## 셀 선택 시 미리보기 동작

결과표 셀을 선택하면 해당 도서에서 관련 페이지 후보를 골라 오른쪽 패널에서 순서대로 보여줍니다.

- `ID`
  - 파일명 순으로 전체 페이지를 보여줍니다.
- 라벨 개수 계열(`텍스트`, `타이틀`, `캡션`, `이미지`, `수식`, `표`, `차트`, `각주`, `아이템`)
  - 해당 라벨 수가 1개 이상인 페이지를 대상으로 내림차순 정렬합니다.
- 텍스트 통계 계열(`띄어쓰기`, `영어`, `기타 외국어`, `특수문자`, `어절`)
  - 전체 페이지를 대상으로 정렬합니다.
- `빈 텍스트 박스`
  - 빈 텍스트 박스가 있는 페이지를 우선 보여줍니다.
- `박스(<2)`, `다단 의심`
  - 해당 지표가 발생한 페이지를 보여줍니다.

미리보기에서 강조 박스 선택 기준도 지표별로 다릅니다.

- 라벨 개수 계열: 해당 라벨 박스만 강조
- 텍스트 통계 계열: 현재 선택한 텍스트 검사 대상 라벨 박스들을 강조
- `빈 텍스트 박스`: 텍스트 라벨 중 실제로 비어 있는 박스만 강조
- `박스(<2)`, `다단 의심`: 페이지의 전체 박스를 함께 보여줌

## 저장 및 외부 반영

### 엑셀 저장

- 파일명: `book_metrics.xlsx`
- 시트명: `book_metrics`
- 저장 내용: 현재 결과표에 보이는 도서 단위 집계값

### 구글 스프레드시트 입력

- `gspread` 패키지가 필요하며, 루트 `requirements.txt`에서 함께 설치합니다.
- 고정 OAuth client secret 파일과 사용자 토큰 파일을 사용합니다.
- 사용자 OAuth 토큰 파일인 `.auth/gspread_oauth_user.json`은 개인 계정 권한이 포함된 로컬 인증 파일입니다.
- 이 파일은 다른 사람과 공유하거나 Git에 올리면 안 됩니다.
- 시트 상단 5행 안에서 `ID` 헤더가 있는 행을 찾아 기준 헤더로 삼습니다.
- 결과표의 `ID` 값을 기준으로 기존 행을 찾아 같은 열만 업데이트합니다.
- 시트에 없는 `ID`는 새로 추가하지 않고 건너뜁니다.
- 대상 시트에 없는 컬럼도 건너뜁니다.

즉, 이 기능은 "기존 검수 시트의 ID 행을 찾아 결과 컬럼만 덮어쓰기"에 가깝습니다.

## 로컬 전용 파일과 산출물

- `client_secret*.json`
  - Google OAuth client secret
  - 로컬 전용 파일
- `.auth/gspread_oauth_user.json`
  - Google OAuth 사용자 토큰
  - 로컬 전용 파일
  - 개인 계정 인증 정보가 포함되므로 공유 금지
- repo 루트 `outputs/`
  - UI 기본 결과 저장 폴더
  - 엑셀 저장 시 기본 경로
- `output/`
  - 이 폴더 하위 `.gitignore`에서 무시하는 로컬 scratch 폴더
- `json_sample/`
  - 이 폴더 하위 `.gitignore`에서 무시하는 실험/샘플용 폴더

이 폴더의 로컬 전용 파일은 `.gitignore`로 관리합니다.

주의:

- `.auth/gspread_oauth_user.json`은 사용자 OAuth 토큰 파일이므로 팀원 간 전달, 메신저 공유, 저장소 커밋을 하면 안 됩니다.
- 토큰이 노출되면 해당 사용자의 스프레드시트 접근 권한이 함께 노출될 수 있습니다.

## 유지보수 포인트

- 텍스트 검사 대상 라벨 옵션은 `label/` 아래 xlsx를 읽어 구성합니다. 읽기 실패 시 기본 라벨 목록으로 fallback 합니다.
- 미리보기 박스 색상도 `label/` 기준표의 color 값을 우선 사용합니다.
- 병렬 처리 수는 `app.common.config.parallel_settings.resolve_parallel_workers()`를 통해 공통 설정을 따릅니다.
- 결과표 컬럼, 도움말, 하이라이트 규칙을 바꾸면 `ui_shared.py`와 이 README를 같이 갱신하는 편이 좋습니다.
- `다단 의심`, `박스(<2)`, `특수문자`처럼 휴리스틱 성격이 강한 항목은 운영 기준이 바뀌면 문서와 코드가 쉽게 어긋날 수 있으니 함께 검토해야 합니다.
