# 기타 도구 탭

독립 실행 성격의 보조 기능을 카드형으로 모아두는 탭입니다.

## 폴더 구조

- `page.py`: 카드 UI와 클릭 흐름
- `loader.py`: `apps/` 아래 앱 자동 로딩
- `base.py`: 각 앱이 따라야 하는 기본 인터페이스
- `apps/`: 앱별 독립 폴더

## 현재 구성 방식

- 폴더 1개를 앱 1개 단위로 관리합니다.
- 실제 사용자용 앱은 `__init__.py`와 대표 `README.md`를 함께 두는 편을 권장합니다.
- 현재는 실제 기능 앱과 새 앱 작성용 템플릿만 유지합니다.

## 새 앱 추가 방법

1. `apps/<app_name>/` 폴더를 만듭니다.
2. `__init__.py`에 `App(BaseMiscToolApp)`를 정의합니다.
3. 카드 제목, 요약, 상태 배지, 엔트리 경로 같은 메타데이터를 채웁니다.
4. 앱의 목적, 현재 상태, 주의사항을 `README.md`에 정리합니다.
5. 필요하면 다이얼로그, 실행 로직, 보조 모듈을 같은 폴더 안에 추가합니다.
6. [apps/README.md](./apps/README.md)에도 앱 목록과 링크를 반영합니다.

### 템플릿 참고 방법

- 새 앱은 `app/tabs/misc_tools/apps/template/__init__.py`를 가장 먼저 참고하는 것을 권장합니다.
- 템플릿에서 우선 확인할 값은 아래 항목입니다.
  - `APP_NAME`: 카드 제목
  - `SUMMARY`: 카드 요약
  - `STATUS_TEXT`: 카드 상태 배지
  - `MODULE_PATH`: 앱 엔트리 경로
  - `run_tool(self, repo_root)`: 카드 클릭 시 실행 동작
  - `build_workspace(self, parent)`: 탭 내부 위젯형 도구가 필요할 때 쓰는 확장 지점
- 새 앱을 만들 때는 템플릿의 `__init__.py` 구조를 기준으로 시작하고, 실제 목적에 맞게 메타데이터와 실행 로직을 바꾸면 됩니다.
- 템플릿은 별도 README를 두지 않고, 이 문서를 기준 안내로 사용합니다.

## 주의사항

- 다른 앱과 강하게 엮이는 공통 로직이 생기면 `app/common/` 이동 여부를 검토합니다.
- 앱 전용 산출물이나 인증 파일이 있으면 폴더 단위 `.gitignore`로 관리합니다.
- 메인 탭의 핵심 워크플로와 분리해야 하는 기능만 misc_tools에 두는 편이 좋습니다.
